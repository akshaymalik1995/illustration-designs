Halftone Assemblage Metaphor PSA Poster - Design Language

A sparse retro PSA poster system where one visible class of material is arranged into a different recognizable symbolic silhouette, printed as a muted blue-green halftone object on aged cream paper with compact red-and-navy campaign typography.

Apply this visual language to whatever subject the user asks for - any medium, any composition. Where a trait below mentions posters, typography, or campaign framing, treat it as optional flavor, not a requirement; the palette, texture, lighting, and mood are the style.

- Style Category: retro environmental PSA poster using symbolic object assemblage
- Semantic Mechanism: The image creates meaning by using one material class to imitate another recognizable object or living form, producing a visual metaphor.
- Layout: portrait-led poster grammar with generous empty cream space, top-left headline, large lower-middle assemblage silhouette, and tiny footer lockup
- Subject Treatment: everyday objects remain individually visible while collectively forming a different silhouette, rendered in blue-green halftone ink
- Perspective: front-facing object study with slight low-angle monumentality and gentle grounding shadow
- Typography: bold uppercase condensed sans, tight word blocks, alternating navy and red emphasis
- Texture: aged paper grain, coarse halftone, uneven ink coverage, and soft offset registration
- Mood: public-service warning with clever symbolic wit and restrained retro charm
