Chromatic Fisheye Orbit Pop Poster - Design Language

Apply this visual language to whatever subject the user asks for - any medium, any composition. Where a trait below mentions posters, typography, or campaign framing, treat it as optional flavor, not a requirement; the palette, texture, lighting, and mood are the style.

- Category: A high-key pop poster system built from extreme fisheye photography, a convex glass-dome center, oversized orbiting typography, hot red-magenta-orange letter fills, aqua chromatic light arcs, and light analog print texture.
- Composition: A reusable poster/image system where the subject, prop, location, text, and accent variables change while the layout grammar remains fixed.
